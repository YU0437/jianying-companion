## 第 0 步：先确认两件事

| 确认项 | 怎么确认 |
|---|---|
| 你装的是 **剪映专业版**（桌面版，不是手机版/网页版） | 开始菜单里能看到「剪映专业版」 |
| 剪映**至少打开过一次** | 第一次打开会生成配置文件，伴侣需要读它来认草稿位置 |

> 没打开过也没关系 —— 装完先打开一次剪映，再启动伴侣即可（伴侣每次启动都会重新认一遍环境）。
> 伴侣**本身不含剪映**，也做不了剪辑，它只是一个"替你按键"的小助手。

## 第 1 步：下载安装包

到项目的 [Releases](../../releases) 页面，下载最新的：

```
剪映伴侣-Setup-1.0.0.exe      （约 22 MB）
```

## 第 2 步：绕过 Windows 的"未知发布者"提示

双击安装包后，Windows 很可能弹出蓝色窗口：

> **Windows 已保护你的电脑**
> 此应用来自未知发布者

**这是正常的**，原因只有一个：作者**没有购买代码签名证书**（个人项目一年要几百到上千元）。
所有没有签名的个人小工具都会这样，不代表它是病毒。

操作：

1. 点窗口里的 **「更多信息」**
2. 出现 **「仍要运行」** 按钮，点它

如果没看到「更多信息」，就点左上角那个小字，或者右键安装包 →「属性」→ 底部勾上
「解除锁定」→ 确定，再双击运行。

> 如果**杀毒软件**（360 / 火绒 / Windows Defender）报拦截：
> 本工具只做两件事 —— **模拟按键、移动窗口**，不读也不写任何视频文件，也没有网络代码。
> 可以放心"允许"或"信任"。

## 第 3 步：选择安装位置

安装程序默认装到：

```
%LOCALAPPDATA%\JianyingCompanion
```

（一般是 `C:\Users\你的用户名\AppData\Local\JianyingCompanion`）

**建议就用默认位置。** 为什么：

> 伴侣的配置文件和运行日志就存在程序目录里。
> 如果你把它装到 `C:\Program Files\...` 这类需要管理员权限才能写的目录，
> 它每次启动都会**保存失败**（你在剪映里改过的快捷键、选过的草稿目录都会丢）。

安装程序会**主动挡住**这种情况 —— 你一选到写不进去的目录，它会当场提示你换回默认目录。

## 第 4 步：安装收尾（它会自己认环境）

安装快结束时，伴侣会**自动跑一次"认环境"**，并把结果念给你听：

- **认到剪映装在哪** → 直接写进配置
- **认到你的草稿放在哪** → 直接写进配置
  （这一步不是"猜常见路径"，而是**直接读剪映自己的设置**，
  所以你在剪映里改过草稿位置它也认得出）
- **没装剪映** → 明确告诉你"没找到剪映专业版"（**不会拦着你安装**，但你得先去装并打开一次）

**你不用做任何设置。** 装完点「完成」就能用。

## 第 5 步：第一次启动

装完后：

- 安装程序会问你要不要**直接打开使用说明**（建议勾上）
- 从开始菜单 / 桌面快捷方式启动「剪映伴侣」

第一次启动时，它会**自动再做一次环境体检**，在悬浮球上告诉你结果：

- 一切正常 → 「体检通过 · 可以开始用了」
- 有缺的 → 球会自己展开，写清楚缺什么

同时你会看到屏幕角落出现一个**小圆球**（默认在剪映窗口的右下角，剪映没开时会贴在屏幕右下角）。
那就是它 —— 平时不挡事，鼠标移上去才会展开显示文字。

## 第 6 步：跑一次

1. 打开剪映，进入**你要处理的那份草稿**的编辑页
2. 在时间线上**选中**要预合成的内容（多选用框选或 Ctrl 点）
3. **左键点一下那个小圆球**

然后看着球上的字做：

| 球上写着 | 你要做 |
|---|---|
| 执行中… / 等待渲染 87s | 什么都别做，等它 |
| **请双击草稿「XXX」卡片打开…** | 切到剪映首页，**双击**它点名的那一张卡片 |
| **请手动把预合成文件拖进时间线** | 先在时间线上按一下 **Home**，再把文件拖进去 |
| **等你导出** | 在剪映里正常导出（不会再提示会员） |
| 导出完了 | **左键点一下球** → 确认 → 自动还原草稿 |

> 任何时候不想干了，都可以**中止**：左键点球（会先问你一句）或右键 →「中止本次流程（自动还原）」。
> 中止后它会**自动把草稿还原回去**，不会留一个半残的草稿。

## 卸载

卸载**不会**删除：

- 你的配置（`伴侣配置.json`）
- 桌面上的草稿备份（`桌面\剪映预合成导出\_备份\`）

想彻底清干净：卸载后手动删掉安装目录和桌面的「剪映预合成导出」文件夹。

> ★ 如果你之前让伴侣给你写过「预合成快捷键」，卸载**不会**把它从剪映里撤掉。
> 想撤掉：启动一次伴侣 → 右键 →「还原剪映快捷键设置」，然后再卸载。
> （或者自己在剪映「设置 → 快捷键」里删掉那一条。）

## 装不上 / 有异常怎么办

| 现象 | 原因与处理 |
|---|---|
| 双击安装包没反应 | 见[第 2 步](#第-2-步绕过-windows-的未知发布者提示)；或被杀软静默拦了 |
| 装完启动不了 | 换成默认安装目录重装（多半是装到了要管理员权限的目录） |
| 球不出现 | 看 `%LOCALAPPDATA%\JianyingCompanion\运行日志.txt`；或用右键菜单的「打开运行日志」 |
| 报"找不到剪映专业版" | 右键球 →「设置剪映路径…」手动指一下 `JianyingPro.exe` |
| 报"找不到草稿目录" | 右键球 →「设置草稿目录…」手动指一下（一般是 `…\Projects\com.lveditor.draft`） |
| 导入报"媒体格式不支持" | 在剪映里点左上角**返回草稿页**让它保存一次，再回到草稿重新拖入 |

更多问题见 [README 的常见问题](../README.md#常见问题)。
