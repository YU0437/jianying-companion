# 剪映伴侣 · Jianying Companion

**简体中文** ｜ [English](README.en.md)

> 把剪映「预合成」之后那段**要重复按快捷键、要手动杀进程、要清空时间线**的活，
> 交给一个悬浮球替你按。**它只模拟键鼠、只摆窗口 —— 不碰、不改、不解密任何视频文件。**

## 这是什么

剪映的「预合成」（把一段内容打包成一个复合片段来导出）在某些场景下会触发会员限制。
但**预合成这个动作本身是剪映自带的、免费的**（`Ctrl+A` 全选 → `Alt+G` 建复合片段 → `Alt+H` 预合成），
真正麻烦的是它前后那一串琐碎操作：

1. 先备份草稿（出错了才回得去）
2. 全选 → 建复合片段 → 预合成
3. **必须让剪映保存一次草稿**（否则重开剪映会把预合成缓存当普通视频，报「媒体格式不支持」）
4. 完全退出剪映、重新打开、回到**原来那一份**草稿
5. 把时间线上原来的内容清空
6. 打开产物文件夹，把预合成好的视频拖进时间线
7. 导出完之后，把草稿**还原回预合成之前**的样子

这套流程手做要十几步，还很容易某一步做错（换错草稿、忘记保存、忘了按 Home…）。
本工具就是一个悬浮球，点一下把 1~6 做完，再把第 7 步做成「点一下自动还原」。

## 它不做什么（红线）

这几条是硬性约束，代码里**有测试守着**（`test_guard.py` 会直接扫源码断言）：

| 不做的事 | 说明 |
|---|---|
| ❌ 解码 / 转码 / 解密 / 改写 / 删除**任何视频文件** | 预合成产物 `<GUID>_video.mp4` 全程**一个字节都不动** |
| ❌ 破解会员、伪造授权、修改剪映程序 | 完全没有这类代码 |
| ❌ 上传你的任何数据 | 程序**不联网**，没有网络代码 |
| ⚠️ 只写草稿目录里的 `.json` | 「还原」功能需要写回草稿元数据，这是唯一会写文件的地方 |

它会写文件的**两种情况**，都提前备份、都如实告诉你：

1. **备份草稿元数据** → 桌面 `剪映预合成导出\_备份\<草稿名>_<时间>_预合成前\`（只拷 `.json`）
2. **还原时写回** → 把上面那份备份写回草稿目录（写之前还会再存一份 `_还原前` 快照兜底）

## 工作原理

```
你点一下悬浮球
   ↓
备份草稿 .json ──→ 桌面 _备份\
   ↓
模拟按键：Ctrl+A → Alt+G → Alt+H        （剪映自带的免费功能）
   ↓
等产物落盘 + 等剪映把「预合成登记」写进草稿元数据
   ↓
杀进程 → 重启剪映 → 等你双击打开原来那份草稿
   ↓
模拟按键清空时间线（Ctrl+A → Del，发完做像素自检，没清掉就报失败）
   ↓
打开 Resources\combination 并选中产物 → 剩下的交给你手动拖 + 导出
   ↓
导出完 → 点悬浮球 → 自动还原草稿到「预合成之前」
```

每一步都用**像素自检 / 文件指纹 / 窗口状态**验证，**做不到就如实说失败**，不会假装成功。

## 安装

### 方式一：下载安装包（推荐，给普通用户）

1. 到 [Releases](../../releases) 下载 `剪映伴侣-Setup-x.y.z.exe`
2. 双击安装。Windows 可能弹「已保护你的电脑 / 未知发布者」—— 因为**没有买代码签名证书**，
   点「更多信息」→「仍要运行」即可（所有个人小工具都这样，不是病毒）
3. **装完就能用**：安装收尾时伴侣会自己认一遍环境（剪映装在哪、草稿放在哪），
   认到就直接写进配置，**你不需要做任何设置**
   - 草稿位置不是"猜"的：它直接**读剪映自己的设置**（剪映 → 设置 → 草稿位置）
4. 默认装到 `%LOCALAPPDATA%\JianyingCompanion`（这个位置**不需要管理员权限**，
   配置和日志才能正常写；安装程序会挡住 `Program Files` 这类写不进去的目录）

详细的图文步骤见 [docs/安装教程.md](docs/安装教程.md)。

```bat
cd jianying-companion
pip install -r requirements.txt   :: 只想跑起来的话，最小是 pip install pillow

```

### 方式三：自己打包

## 快速开始（三步）

1. 打开剪映专业版，进入**你要处理的那份草稿**的编辑页
2. 在时间线上**选中**要预合成的内容（多选用框选或 Ctrl 点）
3. 点悬浮球上的「一键导出」，然后按球上的提示做

> 剪映**没开着**也没关系：点下去它会自己把剪映启动起来、等它就绪后接着跑，**不用点第二次**。

## 界面与操作

平时它就是一个 **46px 的小圆球**，贴在剪映的右下角，不挡时间线。
鼠标移上去会平滑展开成一条横条显示完整文案；需要你动手时它会**自己展开**。

| 操作 | 效果 |
|---|---|
| **左键点球** | 开始「一键导出」；跑完之后再点 = **还原草稿** |
| **左键点球（运行中）** | **中止本次流程**（会先问一句），中止后**自动还原** |
| **右键点球** | 打开菜单（还原 / 中止 / 设置 / 体检 / 打开日志…） |
| 悬停 | 展开看完整文案；移开约 0.3 秒收回 |

### 想中途停下？（可以，而且会自动帮你还原）

两个阶段都能停，**停下来会自动把草稿还原回去**，不会给你留一个半残的草稿：

- **流程正在跑**（球上是「执行中…」）→ 左键点球 → 点「是」
  立刻收手（最长的那段"等渲染 120s"也是**马上**停）→ 还原草稿 → 重开剪映回到这份草稿
- **已经跑完、停在「等你导出」** → 点右键菜单的「中止本次流程（自动还原）」

两个细则：

- 中止时**连预合成都还没发出去**的话，草稿本来就没人动过 —— 伴侣只会停下，
  **不会**去关剪映、也**不会**写任何文件
- 万一这一轮没做出备份，它会**如实告诉你「没能自动还原」**并提示你先 `Ctrl+Z` 撤销 ——
  绝不假装收拾干净了

> 菜单里那条「中止本次流程」在没东西可中止时是**灰色**的 —— 能点，就一定真的能停。

### 导出完之后

球的文字会变成「等你导出 · 导出完点我 → 还原草稿」。
导出完**左键点一下球** → 它问一句"导出完成了吗？" → 确认后把草稿还原成预合成之前的样子。

### 拖文件时有两个要点

- 拖之前先在时间线上按一下 **Home**。剪映是按**播放头位置**落片的，不是按鼠标点的位置
- **不要用 `Ctrl+V` 粘贴** —— 剪映不认，只能真拖

## 它会做哪些"有副作用"的事

| 行为 | 备份 / 还原方式 |
|---|---|
| 备份草稿元数据到桌面 | 位置：`桌面\剪映预合成导出\_备份\`（菜单里能直接打开） |
| 往**你的剪映配置**里写一个「预合成快捷键」（默认 `Alt+H`） | 写之前自动备份原设置；右键菜单 →「还原剪映快捷键设置」 |
| **杀掉剪映进程并重开** | 必须的：剪映完全退出后预合成文件才会落盘 |
| **清空当前时间线**（真删，不是"停用"） | **清空前已备份**，导出后一键还原；清空失败会自检出来并停下 |

## 常见问题

<details>
<summary><b>报「媒体格式不支持」怎么办？</b></summary>

这是**没让剪映保存草稿**导致的。伴侣正常会在预合成后强制让剪映落盘一次
（登记写进 `draft_content.json`），如果那一步没成功，重开后剪映就会把预合成缓存当普通视频解析。

自己救：在剪映里点左上角**返回草稿页**（让它保存一次），再回到那份草稿重新拖入。
</details>

<details>
<summary><b>说"找不到剪映专业版"？</b></summary>

伴侣找剪映的顺序是：①问运行中的进程 → ②读上次自动配置记下的路径 → ③几个常见安装位置。
绿色版 / 装在别的盘 / 自定义目录可能都命中不了。

右键球 →「设置剪映路径…」手动选中 `JianyingPro.exe` 即可。
**一般用不到** —— 装的时候和每次启动时伴侣都会自己去认。
</details>

<details>
<summary><b>说"找不到草稿目录"？</b></summary>

伴侣会**直接读剪映设置里记的草稿位置**（`%LOCALAPPDATA%\JianyingPro\User Data\Config\globalSetting` 里的
`currentCustomDraftPath`），所以你在剪映里改过草稿位置它也认得出来。

真认不出来时：右键球 →「设置草稿目录…」手动指一下（一般是 `…\Projects\com.lveditor.draft`）。
</details>

<details>
<summary><b>杀毒软件报"拦截"？</b></summary>

本工具只做两件事：**模拟按键、移动窗口**。不读也不写任何视频文件，也没有网络代码。
误报主要来自"模拟键鼠"这个行为特征 + 没有代码签名。可以放心允许。
</details>

<details>
<summary><b>它长什么样 / 卡住了怎么办？</b></summary>

- 右键球 →「环境体检」：告诉你这台机器缺什么
- 右键球 →「打开运行日志（发给作者）」：出问题了把这个文件发出来
- 右键球 →「打开使用说明」：随安装包附带的完整说明
- 右键球 →「中止本次流程」：任何时候都能停下来并自动还原
</details>

## 项目结构

```
jianying-precomp/
├── jy_core.py                  # 内核：窗口/按键/像素自检/备份还原/流水线
├── 剪映伴侣.py                  # GUI：悬浮球 + 菜单 + 事件循环
├── 使用说明.txt                 # 随安装包发货的面向用户的说明
├── JianyingCompanion.spec       # PyInstaller 打包配置
├── 剪映伴侣安装包.iss            # Inno Setup 安装包脚本
├── version_info.txt / app.ico   # exe 版本信息与图标
├── 重启伴侣.py                  # 开发用：杀干净 → 覆盖 → 重启 → 复核
├── test_guard.py                # 回归主力：红线 + 形状断言 + 行为断言
├── test_gui_smoke.py            # GUI 冒烟：真起一次 tk 窗口跑一遍
├── test_settle.py               # 文件落盘判定
├── _test_backup_restore.py      # 离线：备份/还原 + 红线守卫
├── _verify_exe.py               # 打完之后验 exe 里到底有没有那些函数和文案
├── requirements.txt             # 依赖与版本
├── ChineseSimplified.isl        # 安装包的中文向导（第三方，见 NOTICE.md）
├── LICENSE / NOTICE.md          # MIT + 第三方资源声明
├── CHANGELOG.md
└── docs/                        # 安装教程 / 构建说明（中英）
```
