剪映伴侣 · 使用说明
========================================

它是干什么的
------------
剪映的「预合成」导出会要求会员。这个工具不做任何破解，它只是**替你按快捷键、
替你摆窗口**：把剪映自己就能做的动作（全选 → 建复合片段 → 预合成）自动做完，
然后把生成的预合成文件交给你，你手动拖进时间线导出即可。

★ 它不碰、不改、不解密任何视频文件，一个字节都不动。它只做"替人按键盘"这件事。

--------------------------------------------------
装完之后（安装包替你做了什么）
--------------------------------------------------
这份东西是**装出来的**，不是绿色免安装。安装过程中它会替你办好三件事：

· **装完就替你认好环境（你什么都不用设）。** 安装收尾时伴侣会自己跑一遍"认环境"：
  剪映装在哪儿、草稿放在哪儿 —— 认到就直接写进配置，装完点「完成」就能用。
  ★ 草稿位置不是"猜"的：它直接**读剪映自己的设置**（设置 → 草稿位置），
    所以你以前在剪映里改过草稿位置，它照样认得出来。
  装完会弹一句话把这些念给你听（认到了什么、写进哪儿了），你确认一下就完事。
· **检查你有没有装剪映。** 伴侣本身不含剪映、也干不了剪辑的活，它只是替你按键。
  没找到剪映时安装包会明确告诉你（不拦着你装，但你得先去装剪映，并至少打开过一次）。
  ★ 就算这会儿没认到（比如你先装的伴侣），下次启动伴侣时它会**再自动认一遍**，
    也不需要你去点任何菜单。
· **挡住"写不进去的目录"。** 伴侣的配置和运行日志就存在程序目录里，
  装到 Program Files 这种要管理员权限的地方，它每次启动都会保存失败。
  你一选到这种目录，安装程序会当场提醒你换回默认目录。

安装完成后还会给你一个勾选框，问你要不要**直接打开这份使用说明**（建议勾上）。
装完第一次启动伴侣时，它会自动再做一次「环境体检」，把缺什么一次性告诉你
（体检里第一条就是"自动配置：已经替你配好了"，写得明明白白）。

★ 默认安装位置：`%LOCALAPPDATA%\JianyingCompanion`
★ 不需要你另外装 Python 或任何运行库 —— 已经全部打包进去了。

--------------------------------------------------
用之前（三步）
--------------------------------------------------
1. 装「剪映专业版」，并**至少打开过一次**（第一次打开会生成配置，伴侣需要它）。
2. 打开剪映，进入**你要处理的那份草稿**的编辑页。
3. 在时间线上**选中**你要预合成的内容（多选就用框选/Ctrl 点）。

然后点伴侣按钮上的「一键导出」。

★ 剪映**没开着**也没关系：点下去它会自己把剪映启动起来，等它就绪后**接着往下跑**，
  你不用再点第二次（冷启动可能要几十秒，球上会写着"正在启动剪映…"）。
  万一等了 1 分钟还没起来，它会明确告诉你"手动打开，再点一次"。

--------------------------------------------------
它长什么样（悬浮球）
--------------------------------------------------
· 平时它就是一个 **46px 的小圆球**，贴在剪映的**右下角**，不挡时间线。
  球是**真透明**的 —— 球外面没有任何方框底板，也点不到球以外的地方。
  球里那个字就是当前状态：`剪` 待机 / `✓` 成功 / `×` 出错 / 数字 = 进度百分比。
  干活的时候球外圈会绕着一道黄色的进度弧，一眼能看出跑到哪了。
· **鼠标移到球上** → 它会像气球一样平滑展开成一条胶囊，把完整文案写给你看；
  鼠标移开约 0.3 秒后自己收回成球。
  展开后最左边那个圆形图标里会跟着显示**进度数字**，和球里的一致。
· **需要你动手的时候它会自己展开**（不用你去悬停）：
  「等你导出」「要你打开草稿」「出错了」这几种状态会自己弹出来 ——
  这几种情况流程正卡在等用户，文字看不见就等于卡死。
· **拖一下就能挪地方**：按住球往哪拖它就往哪走（松手时记住位置，下次启动还在那儿）。
  拖过之后就不再自动吸附角落了；想让它回角落：右键球 →「重置位置（回到角落）」。
· **有消息会从球头顶浮出小卡片**（导完提醒、出错说明、位置已记住…），
  点卡片一下就收掉；球收起来时卡片会一起消失。
· 想换风格：右键球 →「悬浮球」可以在三种之间切换：
      · 自动收纳（默认，就是上面说的）
      · 一直展开（老样子，一直显示全文案）
      · 只留小球（永远只留球，悬停才展开）
· 想换位置：右键球 →「停靠位置」，右上 / 右下 / 左下 / 左上 循环。

--------------------------------------------------
它会做什么（请务必看一遍）
--------------------------------------------------
· 点「一键导出」之后，伴侣会先弹一张**确认卡**（"开始导出？"），
  把"我会做什么"和"要花多久"写清楚，你点「开始」才真的动。
  ★ 这一步很值得看一眼：它会 **清空你原时间线**（真删，草稿会先备份、导出完能还原），
    以前误触一次就直接开跑了，现在多一道确认。
· 会先把你草稿的元数据**备份**到桌面：
    桌面\剪映预合成导出\_备份\<草稿名>_<时间>_预合成前
· 会往你的剪映配置里写一个「预合成快捷键」（默认 Alt+H）。
  ★ 写之前会自动**备份你原来的快捷键设置**；
    想还原：右键伴侣按钮 →「还原剪映快捷键设置」。
    如果 Alt+H 在你机器上已被占用，伴侣会自动换一个没人用的键。
· **会杀掉剪映进程并重新打开**（这是必须的：剪映要完全退出，预合成文件才落盘）。
· **会清空当前时间线**（是真删，不是"停用"）—— 所以务必先确认你现在打开的是
  要处理的那份草稿。清空前会备份，导出后可以一键还原。
· 最后会打开产物所在的文件夹，帮你选中那个文件。**它不会自动拖动**，由你自己拖。

--------------------------------------------------
中途它会让你做两件事（看清球上的两行字）
--------------------------------------------------
需要你动手的时候，球会**自己展开**，并且显示**两行字**：
   第一行 = 你现在该做什么；第二行 = 为什么必须这么做。
（进度百分比不会丢 —— 球外圈的进度弧和展开后的底部进度条一直在走。）

· 【要你打开草稿】发生在它重启剪映之后。它会**点名**是哪一份，例如：
      「请双击草稿「9月18日 (2)」卡片打开… 100s」
      「必须这份 · 换草稿会报「媒体格式不支持」」
  照做即可：在剪映**首页**那一排草稿卡片里，**双击**它点名的那一张。
  ★ 剪映没有"用快捷键打开草稿"这种入口，**只能双击卡片**；
  ★ 点别的草稿 / 新建草稿都不行 —— 预合成的登记只写在做预合成的那一份里，
    换了草稿继续下去必报「媒体格式不支持」。
  你打开之后，伴侣自己会接着往下跑，不用再点它。

· 【请你拖文件】发生在最后。它会把文件夹打开、并选中那个预合成文件，
  等你手动拖进时间线（拖之前记得先按 Home，见下面"拖文件时的两个要点"）。

--------------------------------------------------
全自动导出：连导出都替你按（1.3.0 新增 · 实验，默认关）
--------------------------------------------------
右键球 →「全自动导出（实验）」打开后，流程走到「等你导出」时伴侣会继续：
    自动拖入时间线 → 按导出键（读你剪映的绑法，默认 Ctrl+E）→
    回车确认 → 盯着导出窗口 → 导完**自动还原草稿**
= 从「一键导出」到 mp4 落盘、草稿还原，真正一次点击。

★ 它叫"实验"是因为导出窗口是剪映自己的、每版都可能变。所以任何一步
  没按预期走（拖不进/窗口没出现/回车没反应），它都会**立刻退回手动**，
  屏幕上写清原因 —— 手动导出的路永远通着，还原也随时可用。
★ 全程可中止：中止只是退回手动，不会多做任何动作。

--------------------------------------------------
批量队列：一次排队 N 份草稿，重活全包（1.2.0 新增）
--------------------------------------------------
草稿不止一份？右键球 →「批量处理草稿…」，里面列出草稿目录里**带预合成
素材**的草稿（最多 8 份，最近用过的在前），可以单选也可以「全部处理」。

它会**逐份自动**做完最累的部分：
    自动打开草稿 → 备份 → 预合成 → 等渲染落盘 → 写登记 →
    重启进入 → 清空原时间线 → 落盘 → 下一份
每份跑完都处于「打开即可导出」的状态，之后你想什么时候导就什么时候导
（打开草稿 → 左键点球 → 拖入导出，预合成那步已经做完了）。

· 结束后弹窗会逐份列 ✅/⚠️ 明细；球上只显示一句结论。
· 随时中止：右键 →「中止本次流程」。当前这份会**自动还原**，后面的
  草稿一律不再碰。
· 安全底线和单份流程一样：清空时间线前会核对打开的草稿名（绝不清错）；
  备份没做成的草稿直接跳过；登记没写进去的草稿不清空。
· 开始后大约每份 1~2 分钟，期间请别动鼠标键盘（它要替你按快捷键）。

--------------------------------------------------
导出守望：导出窗口一关，它主动提醒你还原（1.1.0 新增）
--------------------------------------------------
以前导出完还要**自己记得**回来点"还原草稿"。现在不用了 —— 流程进入
「等你导出」后，伴侣会在后台盯着剪映的导出窗口：窗口一关（= 导出流程
走完了，或者你取消了），悬浮球会自己弹出来说「检测到导出完成 · 左键
一键还原草稿」。你点一下，它就把草稿还原到预合成之前。

· 这个功能**只在看，不在动**：它绝不会因为"窗口关了"就自动去关剪映、
  改草稿 —— 也可能是你取消了导出，这种事它不猜。还原永远等你点头。
· 不想要这个提醒？右键球 →「导出守望（导完提醒还原）」关掉即可。
· 提醒出现时如果你已经自己还原过了，它不会再骚扰你。

--------------------------------------------------
想中途停下？（可以，而且会自动帮你还原）
--------------------------------------------------
不想干了随时能停 —— 而且**停下来会自动把草稿还原回去**，不会给你留一个
半残的草稿。两个阶段都能停：

· 流程**正在跑**的时候（球上是「执行中…」或「正在启动剪映…」）：
    左键点一下球 → 它问一句"要中止吗" → 点「是」
    （也可以右键球 →「中止本次流程（自动还原）」）
  它会立刻收手（最长的那段等待渲染 120s 也是**马上**停），然后把草稿
  还原到预合成之前，再重开剪映回到这份草稿。

· 流程**已经跑完、停在「等你导出」**的时候：
    不想导出、想直接收工 —— 同样点「中止本次流程（自动还原）」；
    或者直接左键点球，在"导出完成了吗"里点「是」，效果一样（都会还原）。

★ 两种情况的区别只有一句：
  中止时**连预合成都还没发出去**的话，你的草稿本来就没人动过 ——
  伴侣只会停下，**不会**去关剪映、也**不会**写任何文件（没坏的东西不去修）。
☆ 万一这一轮没做出备份（极少数：认不出你打开的是哪份草稿），
  它会**如实告诉你"没能自动还原"**，并提示你先在剪映里 Ctrl+Z 撤销 ——
  绝不假装收拾干净了。
· 空闲时那条菜单是**灰色**的（没在跑就没什么可中止的）—— 能点，就一定真的能停。

--------------------------------------------------
导出完之后
--------------------------------------------------
· 伴侣按钮会一直显示「等你导出 · 导出完点我 → 还原草稿」。
· 导出完成后，**左键点一下伴侣按钮**，它会先问你一句"导出完成了吗？"，
  确认后就把草稿还原成预合成之前的样子。
  （也可以右键 →「还原草稿（回到预合成前）」。）

--------------------------------------------------
拖文件时的两个要点
--------------------------------------------------
· 拖之前先按一下 **Home** 键。剪映是按**播放头位置**落片的，不是按你鼠标点的位置；
  播放头停在中间的话，片段会插到中间去。
· **不要用 Ctrl+V 粘贴** —— 剪映不认，实测无效，只能真拖。

--------------------------------------------------
第一次装可能会遇到的提示
--------------------------------------------------
· Windows 可能弹「Windows 已保护你的电脑 / 未知发布者」。
  这是**没有购买代码签名证书**导致的，所有个人小工具都会这样，不是病毒。
  想装就点「更多信息」→「仍要运行」。
· 如果杀毒软件报"拦截"：本工具只做两件事 —— 模拟按键、移动窗口，
  不读也不写任何视频文件。可以放心允许。

--------------------------------------------------
出问题了看哪里
--------------------------------------------------
★ 下面三样都能直接从菜单点开，不用自己去找文件夹：
  右键伴侣按钮就看到了。
· 右键伴侣按钮 →「环境体检」：会告诉你这台机器缺什么（剪映没装 / 没运行 /
  草稿目录找不到 / 桌面备份目录写不进去）。
· 右键伴侣按钮 →「打开使用说明」：就是这份文件。
· 右键伴侣按钮 →「打开运行日志（发给作者）」：出问题了把这个文件发给我。
  它就在安装目录下（一般是 %LOCALAPPDATA%\JianyingCompanion\运行日志.txt）。
· 右键伴侣按钮 →「打开草稿备份文件夹」：能看到每一轮预合成前的备份。
  备份位置：桌面\剪映预合成导出\_备份\
  （想自己动手拷回去，就从这个文件夹里拿。）
· 右键伴侣按钮 →「设置剪映路径…」：**如果你的剪映装在非默认位置**
  （绿色版 / 装在 D 盘 / 自己挑的目录），伴侣可能自动找不到它 ——
  表现为启动不了剪映、体检里报"剪映：没找到"。
  ★ 一般**用不到这一项**：装的时候和每次启动时伴侣都会自己去认。
  真认不出来（比如绿色版根本不在常见位置）才需要点它，
  手动选中剪映的主程序（一般是 `JianyingPro.exe`）就好。
  选完之后菜单上会一直显示你指定的文件名；想改回自动查找，再点一次、把对话框取消掉。
· 右键伴侣按钮 →「设置草稿目录…」：**如果你的剪映草稿存放在非默认位置**
  ★ 一般**也用不到** —— 伴侣会直接读剪映设置里记的草稿位置。
  只有体检报"找不到草稿目录"/"目录在但没找到预合成产物"、而且自动认也认不出来时，
  才点这一项手动选中你的草稿文件夹（里面一层一层能看到很多草稿卡片的那一层）。
  选完之后菜单上会显示你指定的位置；想改回自动查找，再点一次、把对话框取消掉。

--------------------------------------------------
如果我关了伴侣 / 重启了电脑呢
--------------------------------------------------
不会丢。只要上一轮还没点「还原草稿」，伴侣按钮重新打开后副标题会写着：
    「上次那轮还没还原 · 右键「还原草稿」」
照着点一下就能还原，不用去找记录。

--------------------------------------------------
卸载说明
--------------------------------------------------
卸载**不会**删除你的配置，也不会删除桌面上的备份。
想彻底清干净，卸载后手动删掉安装目录和桌面的「剪映预合成导出」文件夹。
